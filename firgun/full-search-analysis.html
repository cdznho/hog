Section 1

Integrated Executive Summary

Firgun is brand indexed but category invisible on both search surfaces. Google knows Firgun exists (Ahrefs Health 94, DR 19, 21 referring domains) but has no category pages to rank. LLMs can identify Firgun by name but cannot cite it for conversational founder and LP queries because (a) there is effectively zero on-domain editorial content, (b) there is no Organization or Person JSON-LD, (c) the /newsletter page has almost no body content, and (d) the Framer build renders some text inside components that AI crawlers do not always execute.

The two analyses converge on the same root cause — there is not enough crawlable, entity-linked content on firgun.vc — but prescribe complementary fixes. Traditional SEO says: ship sector pages, a pillar hub, and a signature data report to target high-intent quantum terms. LLM SEO says: prove the entity with schema, write answer-shaped prose for conversational queries, and make the Framer site legible to LLM crawlers. Done together, the same page can rank on Google and be cited by ChatGPT.

The three converging imperatives

BOTH

Start publishing on-domain editorial. Firgun currently has almost no crawlable editorial content on firgun.vc. Activating /newsletter and /insights as active publishing surfaces — not just landing pages — is the single change that benefits both surfaces most.

BOTH

Ship the sector + pillar surface. /sectors/quantum-sensing, /sectors/quantum-computing, /sectors/quantum-communications, and /insights/quantum-venture-capital serve Google's blue-link intent and give LLMs canonical entity-attached paragraphs to quote.

BOTH

Add structured data. Organization, Person (for GPs), FAQPage, Article, and Report schema feed Google's entity graph and AI Overviews, and they also feed the entity-linking pipelines that Perplexity, ChatGPT Search, and Gemini use to decide who to cite.

TRADITIONAL SEO

Capture low-KD commercial terms. Quantum sensing (2,400/mo, KD 13) and quantum venture capital (40/mo, KD 6) are classic Google ranking bets. Volume matters here in a way it does not for LLM SEO.

LLM SEO

Own conversational queries. Founders do not ask ChatGPT "quantum venture capital"; they ask "who funds Series A quantum computing startups in the US?". Write pages that answer those sentences directly, inside the first 100 words, with an entity mention of Firgun Ventures.

Framer Note

Raw HTML audit is priority zero. Before writing new content, curl every existing firgun.vc page with JavaScript disabled. Anything rendered only by Framer components at runtime is invisible to most LLM crawlers (and to basic Googlebot fallback modes). Move key paragraphs into text blocks that appear in server-rendered HTML.

Section 3

Technical Foundation — Crawl, Index, Schema, Entity

Both surfaces need the site to be legible to crawlers — but the second category of crawler (OAI-SearchBot, PerplexityBot, ClaudeBot, GPTBot, Google-Extended) is newer and behaves slightly differently. Complete the Ahrefs-surfaced hygiene items, then add the LLM-specific layer on top.

Ahrefs technical fixes (Week 1)

TRADITIONAL SEO

Remove /404 from sitemap.xml so firgun.vc/404 is not discoverable in the index path.

BOTH

Add missing H1s. Newsletter: "Quantum VC Insights from Firgun Ventures". Careers: "Careers at Firgun Ventures". FAQ: "Quantum Venture Capital FAQ". Google uses H1 for topic relevance; LLMs use H1 to segment pages during retrieval.

TRADITIONAL SEO

Shorten titles. Home: "Firgun Ventures | Series A/B Quantum VC". Portfolio: "Quantum Portfolio & Investment Focus | Firgun". FAQ: "Quantum VC FAQ | Firgun Ventures".

TRADITIONAL SEO

Differentiate meta descriptions. Rewrite home, about, careers, contact, portfolio, and FAQ descriptions to 145–160 characters with page-specific intent. Click-through signal for the Google SERP.

BOTH

Fix image alt text. 48 missing alt references across 11 pages, especially /news. Alt text is both an accessibility and keyword signal — and LLMs use alt text to describe embedded images when answering queries.

TRADITIONAL SEO

Review noindex pages. Legal noindex is fine. /linkedin should be noindex only if it stays as a utility redirect; otherwise replace with a clean 301.

Framer Note — Ahrefs fixes

Titles and meta descriptions: edit per-page under Site Settings → Pages → SEO in Framer. Framer auto-generates H1 from the page title unless you place an explicit text element styled as H1.

Sitemap: Framer generates sitemap.xml automatically; to exclude /404, either mark it as noindex in page SEO or use a custom sitemap override in Site Settings.

Alt text: set on each image via the right-hand properties panel (Accessibility → Alt text). Missing across 48 images on /news suggests a CMS collection needs bulk editing.

Structured data (JSON-LD) — high ROI for both

BOTH

Organization schema on every page with @id = https://firgun.vc/#organization. Include legalName, foundingDate (2024), description, url, logo, sameAs (LinkedIn, Crunchbase, X/Twitter), and numberOfEmployees range. The single entry point that feeds Google's Knowledge Graph and the entity-resolution pipelines used by Perplexity, ChatGPT Search, and Gemini.

LLM SEO

Person schema for each GP (@type: Person, jobTitle, worksFor, sameAs LinkedIn/Twitter, alumniOf, knowsAbout). Google uses this for author E-E-A-T; the real payoff is LLM attribution — when ChatGPT is asked who leads Firgun, Person nodes are how it answers reliably.

BOTH

FAQPage schema on /faq and at the bottom of every sector / pillar page. AI answer engines pull FAQ Q/A pairs directly into generated responses as high-confidence quotes.

BOTH

Article schema on all /insights/ and /newsletter/ pages (author as Person @id, publisher as Organization @id, datePublished, dateModified, headline, description, mainEntityOfPage). Pairs author entity with content entity.

BOTH

Report schema (@type: Report) on /research/quantum-funding-report-2026, with about, datePublished, publisher, and isAccessibleForFree. LLMs flag this type as a citeable primary source.

Framer Note — JSON-LD

Framer does not expose a UI for arbitrary JSON-LD, but it accepts custom <head> HTML per site and per page.

Site-wide: Site Settings → General → Custom Code → End of <head> tag — paste the Organization and Person graph once.

Per-page: Page Settings → Custom Code → End of <head> — for Article, Report, and FAQPage nodes specific to that URL.

CMS-driven: for /insights articles generated from a Framer CMS collection, build the Article JSON-LD once in the collection template using Insert → Code Component and bind fields (headline, datePublished, etc.) to CMS variables.

LLM-specific crawler & infra items

LLM SEO

robots.txt allowlist for GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended, and CCBot. Firgun is a fund brand — no reason to block them. Blocking them (or leaving Framer defaults untested) is the most common silent failure mode for LLM SEO.

LLM SEO

llms.txt at firgun.vc/llms.txt summarising Firgun's positioning, sectors, stage focus (Series A/B), fund size ($250m), portfolio, and canonical URLs for each pillar page. Treat it as a human-readable index for AI crawlers.

LLM SEO

Plain-text prose over rich Framer components. Firgun is built on Framer, which can render content inside JavaScript components that some LLM crawlers do not execute. Audit each page's raw HTML (curl, no JS) and move the key paragraphs into simple text blocks visible server-side.

BOTH

Internal links with precise anchor text. Home, FAQ, About, Portfolio, sector pages, and reports should cross-link with keyword-rich anchors ("quantum venture capital", "quantum sensing startups", not "learn more"). Helps PageRank for Google and entity co-occurrence for LLMs.

Framer Note — robots.txt and llms.txt

robots.txt: Framer generates a default robots.txt but allows custom overrides under Site Settings → General → Custom robots.txt. Paste an explicit Allow rule for each AI crawler user-agent.

llms.txt: Framer does not natively support arbitrary static files. Workaround — create a page at the path /llms.txt, set its response type to plain text via custom code, or host the file on a subdomain / CDN and reference it from robots.txt. Alternative: embed the same summary as visible text on an unlisted /ai-brief page and reference it from robots.txt comments.

Answer-shape rules for every page on firgun.vc

BOTH

Lead with a one-sentence definition or answer in the first 60 words. LLMs preferentially quote the first authoritative sentence; Google uses it for snippet eligibility.

TRADITIONAL SEO

Framer Note — Content structure

Use a CMS collection for /insights, /newsletter, and /sectors. One collection template per type; fields for title, slug, summary, body (rich text), datePublished, author (relation to a People collection). This gives you automatic /insights feed pages, consistent Article JSON-LD, and per-issue newsletter URLs for free.

Avoid "Text with image overlay" components for body copy on ranking pages — they sometimes render only via client-side JS.

Section 6

Distribution — On-Domain Editorial, PR, LP Surface

The highest-ROI distribution change is making firgun.vc the canonical home of every piece of editorial Firgun produces. Every external publication, podcast appearance, or guest essay should route back to an on-domain URL that can accumulate rankings and citations.

6.1 Activate on-domain editorial

BOTH

Make /newsletter an active publishing surface. Each issue published as a standalone URL at /newsletter/<slug> with Article schema (author=Person, publisher=Organization). The page currently lacks an H1 — fix that, then start publishing.

BOTH

Use /insights as the content hub — a feed view across sector essays, founder guides, and market commentary. Every external guest essay (VC Cafe, Forbes, Substack) should have a canonical on-domain version with rel=canonical or precede the syndication.

LLM SEO

If Firgun records any podcasts or videos, publish transcripts on-domain. LLMs do not listen to audio or watch video at retrieval time — a 3,000–6,000 word transcript becomes citeable text that an audio file never will.

6.2 PR and backlinks (Ahrefs data)

TRADITIONAL SEO

Convert existing referrers (Forbes, Substack, Entrepreneur, Crunchbase, Quantum Computing Report, FounderSuite, Supernova Fest, Everything Startups) from homepage links to deep links on sector pages and the research report. Reach out individually — this is where DR-weighted link equity becomes category authority.

TRADITIONAL SEO

Pitch /research/quantum-funding-report-2026 to tier-1 quantum-industry journalists (The Quantum Insider, McKinsey Quantum, Nature, MIT Tech Review) with exclusive data cuts.

LLM SEO

Seek Wikipedia presence for Firgun Ventures and within the "quantum venture capital" / "quantum computing startups" pages. Wikipedia is over-indexed as an LLM training source.

6.3 LP surface

BOTH

/lp and /thesis pages (gated or ungated) describe Firgun's fund model, commercialization thesis, and investment criteria. LPs increasingly brief themselves via ChatGPT / Perplexity before a first meeting; these pages fill the answer.

Framer Note — Editorial pipeline

Build an "Insights" CMS collection once, then route three URL patterns off it by CMS field: type = "newsletter" → /newsletter/:slug, type = "essay" → /insights/:slug, type = "report" → /research/:slug. Framer supports multiple collection pages off a single collection via URL templates.

For guest essays syndicated on VC Cafe, Forbes, or Substack, publish the canonical version on firgun.vc first, then ask the partner to set rel=canonical back. Most partners will — and Google + LLMs will credit firgun.vc.
